 RealBugz - Manual Testing

Overview
  
This repository focuses on practicing manual testing techniques using the RealBugz practice website.
The main goal of this project is to develop manual testing skills, create test cases, execute test scenarios, and document bugs.

 Testing Activities
  
• Creating test cases.
• Executing test cases.
• Recording test results (Pass / Fail / N/A / N/E).
• Documenting bugs.
• Attaching screenshots as evidence when needed.
