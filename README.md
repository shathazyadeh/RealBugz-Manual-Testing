# AssertQA-Manual-Testing

About the Project

This repository contains a Manual Testing project using the AssertQA practice website.
The main goal of this project is to practice manual testing skills, create test cases, execute test scenarios, and document bugs.

Testing Activities

Creating test cases.
Executing test cases.
Recording test results (Pass / Fail / N/A  / N/E).
documenting bugs.
Attaching screenshots as evidence when needed.
